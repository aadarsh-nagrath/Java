# 62. What are the main concepts of OOPs in Java?

[Object-Oriented Programming (OOP)](https://www.geeksforgeeks.org/java/object-oriented-programming-oops-concept-in-java/) in Java is based on four fundamental concepts that help in designing modular, reusable, and maintainable applications.

- [Encapsulation:](https://www.geeksforgeeks.org/java/encapsulation-in-java/) Bundles data and methods into a single unit (class) and restricts direct access to data using access modifiers.
- [Inheritance:](https://www.geeksforgeeks.org/java/inheritance-in-java/) Allows one class to acquire the properties and behaviors of another class, promoting code reusability.
- [Polymorphism:](https://www.geeksforgeeks.org/java/polymorphism-in-java/) Enables a single interface or method to perform different actions depending on the object or context.
- [Abstraction:](https://www.geeksforgeeks.org/java/abstraction-in-java-2/) Hides implementation details and exposes only the essential features to the user.
