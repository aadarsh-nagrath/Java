# 78. What do you understand by copy constructor in Java?

The [copy constructor](https://www.geeksforgeeks.org/java/copy-constructor-in-java/) is the type of constructor in which we pass another object as a parameter because which properties of both objects seem the same, that is why it seems as if constructors create a copy of an object.
