# 134. Explain Treemap in Java

[TreeMap](https://www.geeksforgeeks.org/java/treemap-in-java/) is a type of map that stores data in the form of key-value pair. It is implemented using the red-black tree. Features of TreeMap are :

- It contains only unique elements.
- It cannot have a NULL key
- It can have multiple NULL values.
- It is non-synchronized.
- It maintains ascending order.
