# 125. What is a Vector in Java?

A [Vector](https://www.geeksforgeeks.org/java/java-util-vector-class-java/) is a dynamic array class in Java that can grow or shrink automatically as elements are added or removed. It is similar to ArrayList but is synchronized, making it thread-safe.

- Stores elements in insertion order and allows duplicate values.
- Automatically resizes when its capacity is exceeded.
- Synchronized by default, making it suitable for multithreaded environments.
