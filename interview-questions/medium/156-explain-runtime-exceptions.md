# 156. Explain Runtime Exceptions.

[Runtime Exceptions](https://www.geeksforgeeks.org/java/java-program-to-handle-runtime-exceptions/) are exceptions that occur during program execution and are not checked by the compiler. They usually result from programming mistakes or improper logic.

- Runtime exceptions are subclasses of RuntimeException.
- They do not need to be explicitly handled using try-catch or declared with throws.
- Examples include [NullPointerException](https://www.geeksforgeeks.org/java/null-pointer-exception-in-java/), [ArithmeticException](https://www.geeksforgeeks.org/java/how-to-handle-a-java-lang-arithmeticexception-in-java/), and [ArrayIndexOutOfBoundsException](https://www.geeksforgeeks.org/java/array-index-out-of-bounds-exception-in-java/).
